# Контракт проекта

Единственный файл скилла, который заполняется под конкретный проект. Справочники в `references/` собственных путей и имён не содержат — вместо них стоят placeholder'ы `<слот>` из таблиц ниже.

Пока слот пуст (`—`), скилл не имеет права угадывать значение: сначала бутстрап по `SKILL.md`, потом работа.

Проект: `web-comp-landing.local` — одностраничный лендинг студии «ВЕБ-КОМП»
Платформа: 1С-Битрикс (сейчас статика на PHP-инклудах, ядро подключается позже)
Сборка: `Prepros` (`prepros.config`), npm-скриптов нет

## Пути

| Слот | Что это | Значение |
|---|---|---|
| `<template-root>` | корень шаблона сайта | `local/templates/template/` |
| `<scss-entry>` | точка входа SCSS | `local/templates/template/styles.scss` |
| `<blocks-dir>` | папка файлов BEM-блоков | `local/templates/template/css/blocks/` |
| `<blocks-index>` | индекс блоков и способ подключения | `css/blocks/_index.scss`, через `@forward "<имя>";` |

Что нельзя редактировать: скомпилированные артефакты сборки — `*.css`, `*.css.map`, `*.min.css`, `*.min.js`. Правится всегда исходник. После подключения ядра сюда добавляется `bitrix/`.

## SCSS API

| Слот | Что это | Значение |
|---|---|---|
| `<helpers-import>` | первая строка файла блока | `@use "../helpers" as *;` |
| `<media-xs>` `<media-sm>` `<media-md>` `<media-lg>` | миксины адаптива от меньшего к большему | `sm-block` (767.98) · `md-block` (1199.98) · `lg-block` (1439.98) · `xl-block` (1599.98); есть ещё `xxl-block` (1919.98). Слота `<media-xs>` в проекте нет — самый мелкий это `sm-block` |
| `<hover-mixin>` | миксин hover-состояния | `hover` |
| `<transition-mixin>` | миксин transition | `tr` |
| `<typography-mixin>` | миксины типографики | `h1` `h2` `h3` `price-l` `text-32` `tagline-24` `text-24` `link-24` `text-18` `btn-uc-18` `text-16` `text-14` |
| `<typography-class>` | те же стили классами в HTML | одноимённые классы: `.h1` … `.text-14` |
| `<container>` | класс ограничения ширины | `.container` |
| `<page-wrapper>` | корневой блок каркаса и его зоны | `.wrapper` с зонами `__header`, `__content`, `__footer` |

**Важно для этого проекта.** Токены отступов, кеглей и радиусов сами меняются по брейкпоинтам — они переопределены в `:root`. Поэтому медиазапрос в файле блока нужен **только под смену раскладки** (колонки, направление, порядок). Кегль, отступ или радиус внутри `<media-*>` означает, что вместо токена взято raw-значение, — это ошибка.

Токены переключают только `lg-block` (режим 1200), `md-block` (режим 768) и `sm-block` (режим 375). `xl-block` и `xxl-block` живут внутри режима 1920 и годятся только под правку раскладки.

Внимание на смещение: имя миксина и имя режима Figma **не совпадают** — `sm-block` это режим 375, `md-block` это 768, `lg-block` это 1200. Сверяться по таблице в `design-system.md`, а не по интуиции.

## Токены и темы

| Слот | Что это | Значение |
|---|---|---|
| `<tokens-map>` | человекочитаемая карта токенов | `local/templates/template/css/design-system.md` |
| `<tokens-impl>` | файл, где токены объявлены | `local/templates/template/css/core/_variables.scss` |
| `<token-text>` `<token-muted>` | цвет основного и приглушённого текста | `--text` · `--text-muted` (ещё `--text-soft`, `--text-invert`) |
| `<token-bg>` `<token-surface>` | фон страницы и поверхностей | `--bg` · `--bg-surface` (ещё `--bg-dark`, `--bg-muted`) |
| `<token-border>` `<token-accent>` | границы и акцент | `--border`, `--border-strong` · `--accent`, `--accent-hover`, `--accent-deep` |
| `<token-font>` | шрифтовые токены | `--font-main` плюс `--font-size-xxl … --font-size-xxxs`, `--font-size-price` |
| `<themes>` | темы и способ переключения | тем нет, сайт однотемный; `data-theme` в проекте отсутствует |
| `<design-source>` | исходный макет | Figma `1lQxYxZfvOiCg1IrwC4f9X`; лендинг 1920 — `3791:692`, 768 — `5709:1521`, 375 — `5715:2354`; стайлгайд — `5751:2484` и `5751:2483`, UI-kit — `5751:1440`; бриф — `5850:2761` (десктоп) и `5849:13817` (мобильный) |

Тем в проекте нет, поэтому raw-цвет не ломает вторую тему. Он всё равно запрещён: палитра одна на четыре режима и правится в одном месте.
