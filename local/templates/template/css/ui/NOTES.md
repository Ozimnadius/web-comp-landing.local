# Заметки к стилям UI-примитивов

## `_buttons.scss`

**@mixin btn** · паддинг — токены `Gap-18` и `Gap-24`, сняты с макета. Раньше стояли `15px` и `Gap-40`, выведенные из итоговой высоты: по вертикали сходилось, по горизонтали кнопка выходила 228px вместо 196px.

**@mixin btn** · радиус — `100vmax`, а не `--Radius-Radius-100`. Токен это фиксированные 100px, и на кнопке выше 200px пилюля перестаёт быть пилюлей.

**@mixin btn** · высота — `line-height: 0.6` перебивает интерлиньяж типографики намеренно. В Figma текстовый бокс кнопки обрезан по высоте прописных (`0.75em`), в браузере строка занимает полный em-бокс, и кнопка выходила на 6–7px выше макета. Расхождение сначала приняли, 02.09.2026 закрыли этим числом: высота стала 48,8 / 39,59 / 38,39 / 29,19 против макетных 49 / 39 / 38 / 28.

Точное совпадение дал бы `line-height: calc(0.75em - 2px)` — высота прописных минус рамка, — но константа проще и промахивается не больше чем на 1,2px.

`text-box-trim` тут не работает: свойство применяется к блочным контейнерам, а `.btn` — `inline-flex`, и подпись лежит в анонимном флекс-элементе, до которого селектором не дотянуться.

**Ловушка:** при `line-height` меньше единицы подпись в две строки наложится сама на себя. Кнопки в макете однострочные; если появится многострочная, интерлиньяж ей надо вернуть модификатором.

**@mixin btn-primary** · свечения в варианте нет. Раньше оно стояло тут и доставалось каждой жёлтой кнопке; в макете свечение есть только у кнопки первого экрана (`5703:522`), а у кнопок брифа в тарифах и преимуществах его нет. Убрано 02.09.2026, значение переехало в `.hero__button`.

**@mixin btn-outline-hover, @mixin btn-light-hover** · раскраска наведения вынесена из вариантов отдельными миксинами. Причина: на листе состояний `5751:2483` карточка тарифа в Default и Hover отличается только кнопкой — наведение на карточку подсвечивает её кнопку. Значит раскраску вызывает не только сама кнопка, и «как выглядит» пришлось отделить от «когда срабатывает».

Тела у обоих миксинов сейчас совпадают. Объединять их не надо: это контракты разных вариантов кнопки, и разойтись они должны молча, не потянув друг друга.

**@mixin btn-light** · hover выведен, а не снят с макета. Вариант нужен для кнопки в тёмной карточке тарифа (`5702:354`), но на листе состояний `5751:2483` тёмной карточки нет вовсе. Жёлтая заливка взята по остальным трём вариантам: все они на hover уходят в жёлтый. Заменить, когда дизайнер нарисует.

**.btn--compact** · единственное место, где `line-height: 0.6` базовой кнопки перебивается обратно на единицу. Кнопки брифа (`5849:8755`) набраны кеглем 16 без капса, высота в макете 35. С базовым интерлиньяжем выходило 31,6, с единицей — 38: попасть точно ни одним из двух нельзя, взята единица — лишние 3px в подвале окна не видны.

Паддинг задан через `--btn-padding` — `Gap-10` / `Gap-18`, то есть по токену мельче базовых `Gap-18` / `Gap-24`. Заливку и hover модификатор не трогает вовсе — цвет приносит вариант, поэтому в разметке он идёт с ним в паре: `btn btn--primary btn--compact`.

## `_main.scss`

**.sticky-column** · `align-self: start` обязателен. Элемент грида по умолчанию растянут на всю высоту ряда, и прилипать ему тогда некуда: `position: sticky` молча ничего не делает. Ниже 1200 колонки во всех секциях встают друг над другом, поэтому там `position: static`.

**a:not(.btn)** — глобальный hover ссылок исключает кнопки намеренно. Варианты `.btn` в hover задают только рамку и фон, поэтому `a:hover` дотягивался внутрь компонента и перекрашивал подпись. Добавлять `color` в каждый вариант — лечить симптом.
