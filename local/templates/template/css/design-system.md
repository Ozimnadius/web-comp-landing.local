# Дизайн-система «Веб-Комп»

Карта токенов. Правило проекта: любой текст берёт класс или миксин, любая кнопка — класс или миксин, любой отступ, радиус и цвет — переменную.

Источники в Figma: [типографика и цвета](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5751-2484) · [компоненты](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5751-1440) · [состояния hover](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5751-2483)

Реализация — [`core/_variables.scss`](core/_variables.scss), типографика — [`ui/_typography.scss`](ui/_typography.scss), кнопки — [`ui/_buttons.scss`](ui/_buttons.scss).

Сайт однотемный: тёмные hero и подвал — фон секции, а не тема.

## Брейкпоинты

Переменные Figma собраны в четыре режима по ширине. **Диапазон называется по своей минимальной ширине:** `xl` — это полоса 1600…1919.98, и макет для неё нарисован на 1600.

| Миксин | Диапазон | Макет полосы | Режим токенов |
|---|---|---|---|
| — | выше 1919.98 | [1920](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=3791-692) | 1920 |
| `xl-block` | 1600…1919.98 | [1600](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5703-494) | 1920 |
| `lg-block` | 1440…1599.98 | [1440](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5707-498) | **1200** |
| `md-block` | 1200…1439.98 | [1200](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5709-1027) | 1200 |
| `sm-block` | 768…1199.98 | [768](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5709-1521) | **768** |
| `xs-block` | 375…767.98 | [375](https://www.figma.com/design/1lQxYxZfvOiCg1IrwC4f9X/Web-Comp---Landing--01.09.2026-?node-id=5715-2354) | **375** |

**Ловушка.** Имя миксина и имя режима не совпадают: `xs-block` — режим 375, `sm-block` — 768, `lg-block` и `md-block` оба — 1200. Токены переключают только `lg-block`, `sm-block` и `xs-block`; `xl-block` и `md-block` попадают в режим соседа сверху и годятся лишь под смену раскладки.

Медиазапрос в файле блока нужен только под раскладку. Кегль, отступ или радиус внутри него означает, что вместо переменной взято сырое число.

## Именование

Имена повторяют имена переменных Figma один в один: группа и имя через дефис, пробелы в дефисы. `Font Size / Font Size XS` → `--Font-Size-Font-Size-XS`. Семантического слоя нет. Служебные переменные проекта пишутся строчными: `--container-width`, `--container-padding`, `--header-height`, `--transition`, `--radius`, `--btn-padding`.

## Цвета

Одинаковы во всех режимах.

| Переменная | HEX | Где |
|---|---|---|
| `--White` | `#ffffff` | фон страницы, карточки, текст на тёмном |
| `--Black` | `#14171c` | основной текст, рамка кнопки Linear, фон hero и подвала |
| `--Yellow` | `#ffc600` | заливка кнопки Default |
| `--Yellow-Hover` | `#ffdb60` | заливка на hover |
| `--Orange` | `#f2ad00` | нумерация преимуществ, hover ссылок и иконок |
| `--Grey` | `#f1f2f4` | фон секции тарифов, фон поля ввода |
| `--Grey-2` | `#eaeaea` | роль не подтверждена |
| `--Grey-3` | `#c5c5c5` | рамка карточки преимущества, вотермарк подвала, разделитель метрик на 375 |
| `--Grey-4` | `#b2b2b2` | надзаголовок секции — «Тарифы» |
| `--Grey-5` | `#6c6c6c` | описания и подписи |

«Роль не подтверждена» — цвет в коллекции есть, применения в разобранных узлах не нашлось. Проверить при вёрстке своей секции, не выдумывать.

**Вне коллекции** — четыре цвета формы, лежат сырыми значениями в `5702:656`. Переменные заведём на этапе формы: `#ff5a1f` (звёздочка обязательного поля, тот же оттенок в свечении кнопки), `#e3e5e9` (рамка поля), `#757575` (плейсхолдер), `#5b616a` (подпись над полем).

## Контейнер и шапка

```
--container-width: 1770px;              // 1920 − 2 × 75, ширина фрейма Hero section
--container-padding: var(--Gaps-Gap-75);
--header-height: расчёт из токенов шапки
```

`--header-height` выведена формулой, а не константой: шапка вынута из потока, её высоту надо знать снаружи, и она разная на каждой полосе. Проверять замером после правок кнопки.

## Шрифт и типографика

**Geologica**, вариативный woff2, оси `CRSV`, `SHRP`, `slnt` запинены, `wght` 300–500. Подключение — [`core/_fonts.scss`](core/_fonts.scss).

Каждый стиль — миксин плюс одноимённый класс. Медиазапросов внутри миксинов нет: кегль приходит переменной.

| Класс / тег | Стиль Figma | weight | Кегль | line-height | прочее |
|---|---|--:|---|--:|---|
| `h1` / `.h1` | Heading 1 | 400 | `XXL` | 1 | |
| `h2` / `.h2` | Heading 2 | 400 | `XL` | 1 | |
| `h3` / `.h3` | Heading 3 | 400 | `X` | 1 | |
| `.price-l` | Price L | 500 | `Price Size` | 1 | |
| `.text-32` | Text 32 | 400 | `L` | 1 | |
| `.tagline-24` | Tagline 24 | 400 | `M` | 1.42 | `uppercase` |
| `.text-24` | Text 24 | 300 | `M` | 1.28 | |
| `.link-24` | Link 24 | 400 | `M` | 1.42 | `underline` |
| `.text-18` | Text 18 | 300 | `S` | 1.42 | |
| `.btn-uc-18` | Text Btn UC 18 | 500 | `S` | 1 | `uppercase` |
| `.text-16` | Text 16 | 400 | `XS` | 1.42 | |
| `.text-14` | Text 14 | 400 | `XXS` | 1.42 | |

Под `XXXS` именованного стиля в макете нет — переменная доступна, класса нет.

## Кнопки

Форма — пилюля `100vmax`, типографика — `btn-uc-18`, паддинг — `Gap-18` / `Gap-24`. Геометрия правится на месте через `--btn-padding` и `--radius`.

| Модификатор | Вид | Hover |
|---|---|---|
| `.btn--primary` | жёлтая заливка, чёрный текст, свечение `0 13.715px 16.458px rgba(255,90,31,.55)` | заливка `--Yellow-Hover` |
| `.btn--outline` | прозрачная, рамка `--Black` | жёлтая заливка |
| `.btn--invert` | прозрачная, белая рамка на тёмном | жёлтая заливка, чёрный текст |
| `.btn--light` | сплошная белая, чёрный текст | жёлтая заливка |
| `.btn--block` | во всю ширину родителя | |

`.btn--light` стоит в тёмной карточке тарифа. Hover для неё в макете не нарисован и выведен по остальным вариантам — см. [`ui/NOTES.md`](ui/NOTES.md).

Кнопка выходит на 6–7px выше макета — принятое расхождение, разбор в [`ui/NOTES.md`](ui/NOTES.md).

## Ловушка: url()

Путь внутри `url()` резолвится от собранного `styles.css` в корне шаблона, а не от партиала. Шрифт подключается как `url("fonts/...")`, ассеты — абсолютным путём от корня сайта: `url("/upload/images/...")`.

## Открытые вопросы

1. **Ширины текстового блока hero** на полосах `xl`, `lg`, `md` из макета не сняты.
2. **Иконки «плюс/минус» для FAQ** Figma не отдаёт как SVG — собираются в CSS.
